## Create Folder Structure

* You can refer the link:https://github.com/RedHatQuickCourses/etx-virt_delivery/blob/self-paced/content/ansible/vars.yml[var file] for the vSphere folder structure.
+
image::VMware/folder_structure.png[link=self, window=blank, width=100%]

* First create the parent folder `ETX-Self-paced` and `Templates` folder in case not created.
* Assign the `Administrator` role to user for `ETX-Self-paced` folder.
+
image::VMware/access_folder.png[link=self, window=blank, width=100%]
* Under `Templates` folder create `ETX-Self-paced-Templates` folder.

## Create VM Templates in vSphere Cluster

* You will need to create the VMs manually first. In current setup, VMs were created using ISOs first.
* You can convert any powered off virtual machine to a template by calling `VirtualMachine.MarkAsTemplate`.
* After the conversion, the original virtual machine no longer exists.
* You can use the template to create multiple clones of the same configuration.
* You can give same link:https://github.com/RedHatQuickCourses/etx-virt_delivery/blob/self-paced/content/ansible/vars.yml[template name] as in lab exercise to work with automation.
* You can save the templates in `Templates` > `ETX-Self-paced-Templates` folder.

## Create VMs in vSphere Cluster

* Update the `vsphere_host`, `vsphere_user`, `datacenter`, `cluster`, and `datastore` variables as per your environment in the link:https://github.com/RedHatQuickCourses/etx-virt_delivery/blob/self-paced/content/ansible/vars.yml[var file].
* Follow the instructions in link:https://github.com/RedHatQuickCourses/etx-virt_delivery/blob/self-paced/content/ansible/readme.md[readme] file to create and remove the VMs on vSphere cluster.
